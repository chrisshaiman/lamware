# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

**The short version:** be professional, be respectful, critique code not
people, and assume good faith. Harassment and personal attacks are not
tolerated anywhere in the project's spaces (issues, PRs, discussions).

Given the subject matter, one addition: discussion of malware, exploitation
techniques, and threat actors is on-topic here **for defensive purposes**.
Using project spaces to request or share help with *conducting* attacks,
building offensive tooling, or distributing samples is a conduct violation
and will result in a ban.

## Enforcement

Report conduct issues privately via
[GitHub private reporting](https://github.com/chrisshaiman/lamware/security/advisories/new)
(the same channel as security reports — mark it as a conduct report).
Reports are handled confidentially by the maintainer. Consequences follow
the Contributor Covenant enforcement ladder: correction → warning →
temporary ban → permanent ban.
